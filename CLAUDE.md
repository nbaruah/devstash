## Commands

- `npm run dev` — start the Next.js dev server (default http://localhost:3000). Running this rewrites the `<!-- BEGIN:nextjs-agent-rules -->` block in `AGENTS.md`; commit that regeneration with your work.
- `npm run build` — production build.
- `npm start` — serve the production build.
- `npm run lint` — ESLint flat config (`eslint.config.mjs`). No test runner is configured.
